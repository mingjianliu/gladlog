## 四、三个提取 bug + 一层认知问题(新 session 绝不能重新踩)

前三个是**逐行读原始 log 抓到的,聚合统计一个都测不出来**。

1. **单排每轮重新分队**并重发 COMBATANT_INFO。队伍归属必须按 `(round, guid)` 存;
   按 `guid` 存会用最后一轮的分队解释前 5 轮,敌我全反(渲染出来能看到
   「队友对队友放凶猛撕咬」)。
2. **时间戳的时区偏移没有分隔符**。毫秒**恰好 3 位**:`23:02:36.8108` = 810ms + UTC+8,
   `20:12:04.937-4` = 937ms + UTC−4。正则必须 `\.(\d{3})`;写 `\.(\d+)` 会把 8108
   读成 8.108 秒,每行加的量还不同 → 事件顺序乱掉。语料 **41%** 的行受影响。
   实测对 pass1 的影响:38% 对局时长有偏差(中位 2.9s / 1.2%,最大 55s / 33%),
   施法计数不变。
3. **无目标施法的 destName 是不带引号的 `nil`**。前缀正则写 `,"([^"]*)",` 会整条丢掉 ——
   图腾 / 宁静 / 光环掌握 / 复仇之怒,几乎所有大 CD 都是无目标。写成 `,"?([^",]*)"?,`。
   **修正幅度(2100+ 总施法/分中位)**:织雾 18.2→33.7、恢复萨满 20.7→32.9、
   恢复德鲁伊 26.4→34.8、神圣牧师 22.9→29.4、戒律 23.8→29.1、神圣骑士 25.6→29.6。
   HPS / 溢出 / 护盾 / 承压几乎未变(治疗与伤害事件本来就带目标名)。
4. **不是所有 `SPELL_CAST_SUCCESS` 都是按键**。三类要剔除,已登记:
   - `passive_ids.json` —— 被动触发。仓库 `PASSIVE_SPELL_BLOCKLIST` 的 8 个英文名,
     拿 900 场语料解析**只剩 1 个活着**(Reclamation 415388,占神圣骑士 24% 的「施法」)。
   - `copy_ids.json` —— 回响复制体与套装触发。`360995 青翠之拥` 86% 与 `361195` 同刻;
     `355941 梦境吐息` 同理;`1265980/1265991 孪生烈焰` 独立出现率 0.1%、与裂解 100% 同刻;
     `361509 活化烈焰` 75% 与时序烈焰同刻。不剔除的话奶龙每轮施法数**翻近一倍**。
   - `copy_ids.json` 还包含**引导跳动**(后加,2026-08-23 晚):`64844 神圣赞美诗`
     相邻间隔 1.00s、每轮 5–6 跳,把引导的每一跳当成施法 → 虚高 **5 倍**
     (18,504 → **3,583** 次真施法);`157982 宁静` 0.80s;`450215 虚空冲击` 1.00s。
     判据是**同轮内相邻两次间隔 ≤1.05 秒**。
     ⚠️ 阈值**不能放到 1.4s**:`愤怒`/`恳求` 这类真填充技能的间隔就是 1.4s。
   - **同一次按键记两条**(后加):`10060 能量灌注` 给队友时同刻记「给队友」+「给自己」,
     间隔 0.00s,n=90,269。`seq.load()` 现在按 `(t, spellId)` 去重。
   - ⚠️ **独立出现率不能单独当判据**:治疗链 0.8%、神圣赞美诗 0.0% 也很低,但它们是
     真按键(总有别的东西同刻触发)。必须结合「伴随对象是否单一」+ 人工确认。

**这一层是读一位单排第一名的奶龙视频讲解才认出来的**,不是靠统计。他原话
"consuming essence burst sends forth a living flame at 50% effectiveness.
And then twin flame also goes as well" 直接解释了日志结构。
**结论:玩家的口头讲解应常态化用来校准提取器**,`check_video.py` 是把这类断言
变成语料判据的模板。

另外两条口径修正,已在普查报告里但**产品侧还没修**:
- 承压漏掉吸收:戒律 39.0% / 神圣骑士 32.6% / 织雾 22.9% 的入伤只在 `SPELL_ABSORBED` 里。
- 溢出治疗率四个分档全平(戒律 46→47%,德鲁伊 40→39%)——**负结果,别做成判据**。

## 五、剩余工作:八类从没读过的日志事件(按价值排序)

探针 `gap_probe.py`,下面的量级是 300 场 / 610 回合实测。这些不是精度问题,
是**整类判断做不出来**。

1. ~~**控制的真实时长**~~ —— **这条是错的,2026-08-23 晚更正**。
   产品**是**算的:`ccTrinketAnalysis.ts` 的 `ICCInstance.durationSeconds` 就是
   apply/remove 配对出来的,`resourceSnapshot` 还有 `lockoutDurationSeconds`。
   语料侧的量级仍有参考价值(治疗每回合被控 **15.2 次**,中位 3.0s,33% ≥4s),
   但**不是缺口**。真正缺的是**锁定期内的行为**,见下面新增的第 0 条。

0. **被打断之后:瘫痪还是换学派**(新增,价值最高且数据现成)。
   `kickEatenEvents` 的代码注释自己挂着这个问题:「840 条锁定时长全部落在 3–4s
   (现代 WoW 学派锁定固定),按 `lockoutDurationSeconds` 排序等效稳定序……
   若将来要挑「代价最高的被断」,需要新的排序谓词」。**这就是那个谓词**。
   `SPELL_INTERRUPT` 的 **index 11 = 被打断的法术 id,index 13 = 被锁的学派掩码**
   (不用查 `spellSchoolsGenerated.json`)。探针 `school_probe.py`,500 场实测:

   | 专精 | 被踢后 5s 内换学派 | 整整 5s 没动作 |
   |---|---|---|
   | 戒律牧师 | 76–80% | 6–10% |
   | 生命缚誓者 | 76–84% | 6–7% |
   | 恢复德鲁伊 | 51–57% | 2–9% |
   | 神圣牧师 | 36–38% | 21–22% |
   | 恢复萨满 | 16–24% | 18–32% |
   | 神圣骑士 | **8%** | **36%** |

   排序与各专精能力上限吻合(戒律 12.1 把闪现治疗永久升级成暗影愈合 = 两个学派;
   萨满单学派 + 风剪 30s CD)。所以它是**能力上限 × 技术水平**的混合量,
   同专精内部比时「没动作率」才是可教的那一半。
   ⚠️ 恢复德鲁伊的「换学派」里相当比例是 `熊形态/猎豹形态`,是否真在打输出/治疗要另判。
2. **资源可读** —— advanced 参数 `f[21]/f[22]/f[23]` = powerType/currentPower/maxPower。
   powerType 0=法力、3=能量、19=精华。治疗施法时法力比例中位 74–88%,最低到 1%。
   这就是 CLAUDE.md 价值门第 3 条要的**可行性门**(当时按得出来吗)。
   BACKLOG #26 的 mana 候选当初被毙是因为缺敌方爆发上下文,不是读不到数。
3. **免疫 / 未命中** —— `SPELL_MISSED` 的 missType:**IMMUNE 35,006 次**
   (还有 ABSORB 174k / REFLECT 1.5k)。打进免疫、打进 DR 免疫的控制,现在一次都抓不到。
4. **伤害转移** —— `DAMAGE_SPLIT` 每回合 **199 次**(牺牲祝福等)。承压两边都算错;
   叠加吸收漏算,「谁在被集火」有两个系统性偏差。
5. **充能等级** —— `SPELL_EMPOWER_END` 最后一个字段。梦境吐息 1 级 319 次 vs 3 级 34 次。
6. **控制被什么打断** —— `SPELL_AURA_BROKEN_SPELL` 每回合 **12.8 次**。
   ⚠️ 打断者 GUID **不在事件里**,要靠同刻伤害事件反推。
7. **治疗被吸收** —— `SPELL_HEAL_ABSORBED` 每回合 **145 次**,HPS 完全没算这一层。
8. **假读条** —— `SPELL_CAST_START` 无配对 SUCCESS。治疗未完成率 19–20%,
   **三个分段完全持平** → 光看率没有判别力,价值在拆成「骗到踢/被踢掉/自己取消」三类。

**否定(他说必做,场上没人做)**

- 神牧「进赞美诗前先给队友能量灌注」—— 实际只有 **14.0%**(已剔除引导跳动后的真施法 n=3,583)
- 神牧「天使长接赞美诗」—— **1.1%**,这个连招在场上不存在
- 萨满「生命释放垫一发大治疗波」—— 只有 **36.7%(Totemic)/ 44.5%(Farseer)**

**揭示提取缺口** —— 三条断言卡在同一个能力上(已写进 BACKLOG #36 (h)):

| 断言 | 要什么 |
|---|---|
| 治疗波/治疗链要打在**带激流**的目标上 | 施法瞬间**目标身上**的光环 |
| 接地图腾要在敌人**读条中**按下 | 敌方 `CAST_START` ↔ `SUCCESS` 配对的读条窗口 |
| 迅捷治愈按顺序吃 回春术→野性成长→愈合,**别让回春术被吃掉** | 施法瞬间目标身上的 HoT 集合 + `AURA_REMOVED` 归因 |

`aurasActiveAt`(`momentSnapshot.ts`)原语已有、`SPELL_CAST_START` 解析层也有,
**缺的是消费者** —— 没有任何判据问过「你按这一下的时候,目标身上该有的东西在不在」。

**方法结论**:每个赛季初把主流攻略的文字稿过一遍,当成提取器的回归测试集。
本轮 (a) 里那三种「不是按键」的形态,统计判据试了三轮都分不开,
是第一名奶龙视频里一句话点破的。
