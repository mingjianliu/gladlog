# 当前方向:事实层与解析,不做拍脑袋的新指控

## 用户方向(2026-10-07)

> 「如果想继续深挖的话,我希望我们就不要去做这种拍脑壳的、新的规则和决定了。我想做的是把事实层和 parsing 这一层,把游戏的真实状态彻底理解、吃透、弄明白,我们关注在这方面。」

同日用户关掉两个已探针「过了」的新指控:效应只有 2–3 pp,而且取决于挑哪个门槛、哪个对照口径、哪个收窄条件。原话:「这种拍脑袋的东西,我以后不想做了」。

**Why**:大规模评测显示错误大头在**我们给模型的信息**(菜单 / 数据),换模型结论 INCONCLUSIVE;手调的新指控效应小、依赖阈值。

10-16 再确认(经 round1+2 转述):「**我现在只关心事实层的东西**」。同日用户在另一个会话里说事实层「比之前好很多,但上面更抽象的那一层还没做」,让那个会话写了抽象层前两步的工单(`docs/plans/2026-10-16-residual-triage-and-episode-view.md`,第 0 步只分类、不改代码)。两句不矛盾:**事实层是现在做的事,抽象层只量不建**,第 1 步开工前问用户。

## How to apply

- 优先级:解析器正确性(没读的事件、字段布局、丢失的 REMOVED / 重播、单位 / 宠物 / 召唤物、时间戳)→ 事实层对游戏的忠实度(官方 DB2 + 日志证据:时长、免疫、施法距离、视线、冷却状态、谁做了什么)→ 对照渲染文本核实事实的门。
- **不要**提新指控类型、新阈值、新教练「规则」。残余错误若暗示需要一条,记下来问用户。
- **任何新指控 / 菜单事件类型开工前先问用户**,即使探针「过了」。结论取决于「我来挑门槛 / 挑对照口径 / 挑收窄条件」的,把这点说在最前面,默认建议不做或只做零判断的事实行;不要先跑大规模探针再让用户裁一堆口径。
- 评测残余错误三分:**模型错 / 我们给错了输入 / 日志给不了**,精力放中间那类和「从日志还原真相」。

## 事实行是现成样板

- 事实行不指控、不删事实,只陈述;改动先在 issue 上写契约再量。**想指控又怕冤枉 → 把可行性证据写进事实行,判断留给模型**,比建候选类型便宜两个数量级。
- 消费结果通常是「改解释不改判决」。
- 现有例子:`[CD PRIOR]`(群体交牌血线中位作为 context,不做按牌的硬阈值)、`[ROOT]`(定身的价值 = 被定的人从那个位置够不够得到目标;定身**不进** DR 表)、`[ENEMY DEF] | during it:`(对方吃外置期间每个友方打了多少)、`[CONSEQ]`、`[FORCED TRINKET]`、owner CC 打空标记(`[MISSED on X — …]`、`[REFLECTED by X]`;ABSORB 不算失败)、假读 / 停读条。
- 后果句规则(GH #70):**允许**可观测后果和建议理由;**禁止**归因输赢、对本场的笃定反事实、未呈现的状态。

## 已经走过的路(别从「加一个字段」重新开始)

- **归因接地审计(2026-08-16)**:动词(这件事发生过吗)扎实;名词(哪个技能算 X)薄;副词(这算不算错误)基本没依据。从来没有机制验证过「这条判断是对的」——标定只测发生率、模型行为、确定性。有效的接地都把判断的某条事实腿接到外部权威(天赋感知、种族、驱散能力门)。所有手工白名单对「不在名单里」都倒向发出断言而不是弃权。
- **「全是启发式」(2026-09-12)**:高层想法 = 共享的时间证据服务——每条断言声明前提、来源、已知 / 估计 / 未知、允许的表述强度;做不了意图与最优反事实(归档给的是 P(结果 | 历史, 动作, 人群),不是干预量)。给人更多事实卡,人会用,但判断几乎不变。逐条信号路线接近天花板,杠杆在插件 / 画面数据、学出来的先验、对照高手回合(BACKLOG #49 / GH #49——先 backlog,随后 2026-09-05 用户裁「49 也不做」,已关;别再提「专家标注决策数据集」这一形态,它就是 #49)。
- **形态(2026-09-24)**:摆脱逐回合失误清单的几个形态,用户否了——要的是**单局可靠性**。
- 新想法先问三件事:前提是什么、日志能不能观测(已知 / 估计 / 未知)、允许说到什么强度。

## 深挖实验的结论

- 深度瓶颈 = 递归纪律 + 评审人上下文,不是模型能力。用户的深度标杆:单点读数不算 finding,合格线是反事实因果链。
- **自由臂**(可写任意确定性脚本 + 直读 raw.txt)在已挖过的对局上又找到新发现(死因重定性为法力死亡)——约束臂被锁在解析层。**「X 无数据」常是解析层边界,不是日志边界。** 正确形态 = 自由臂探盲区 → 补工具 → 约束臂日常化。
- per-spec 过门率差异是结构性的(阵容结构、死法),**不做 spec 定制参数**(用户铁律)。
- 时刻级深挖 N=20 盲配对胜率 35.7%,按用户「B 不赢就不用」弃用,只留 `momentSnapshot.ts` 原语。
