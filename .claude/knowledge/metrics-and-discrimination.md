# 指标、判别力与分层

## 判别力先按机会归一化

候选类型的「判别力」(输局触发率 − 胜局触发率)在**机会本身与胜负相关**时会给出反向假信号。

- 实例(2026-08-19,missed-sync-window):发生率判别力 −4.4 pp(「赢时触发更多」),看似有害。拆开:胜局场均机会窗 8.30 vs 负局 7.19(控得多 = 机会多 = 没打满的窗口也多);**按机会归一化的转化率胜 26.7% vs 负 27.8%,持平**——行为本身与胜负无关,信号前提不成立,下架。
- 做法:算判别力前先问**分母是什么、它与胜负是否相关**;相关就换成「转化率 = 抓住的机会 ÷ 总机会」,胜负分桶比。转化率也持平 → 信号无料,修实现救不回;转化率有差 → 才值得修实现。
- 用户问「是不是实现问题才起反效果」时,要把「评测口径的实现问题」和「信号本身没料」分两层回答。

## 尺度压缩 ≠ 一致性提升

改评分 rubric 后,「极差 / 方差降了」不等于「评分者更一致了」。改锚点映射会同时改尺度:一个错原本扣 2 分现在扣 1 分,任何由「差一个发现」造成的分差都自动减半——噪声减半,信号也减半,判别力净变化为 0。

- 2026-07-21 判官校准:登记的 accuracy 极差 1.00 → 0.80 → 0.50,看着是连续改进;换算到判官各自找到的错误条数后是 0.50 → 0.30 → 0.50,最新一轮其实退回起点。
- 做法:先找一个**不随锚点变化的底层计数**(如 factAudit 里 refuted / unsupported 条数)当主判据。若分数已是该计数的确定函数,分数指标不再携带额外信息。

## 分层:胜负是循环轴,分段是外部真相

- 这个语料**按 bracket 池化必出假效应**(bracket 组成随分段移动)。`aggregateGradient` 只接受单一分层,单测守着。
- 用户 2026-09-11 裁:不再按评级分段出表(语料少、分段随赛季漂移),保留角色与 bracket 切分;要比分段时用 (赛制, ISO 周) 内的百分位,绝不用绝对分(赛季通胀)。
- **梯度测的是能动性**:负梯度全是「你该按没按」,正梯度全是「别人对你做了什么」——对手能动性信号按构造无法用分段轴验证。
- 公开 feed 的「2100+ 对照组」不等于「比这个玩家强」,对照给双口径。

## 小样本外推

没有逐例机制就改产品 = 拿聚合数字外推。小样本外推多次差点成立:3,246 场 39% → 全量 29.7%;20 场 88% vs 36% → 扩样后消失。

## 异常高的结果率先查「是不是已经输了」

结果率异常高(86% vs 对照 11%)的指控,先查是不是回合已经输了(「队友危机里治疗发呆」其实是「2v3 之后治疗不操作了」)。「浪费类」指控两连败之后,此类想法先跑**回合内配对 DiD** 探针。

## 新判据至少换一个视角复验

治疗视角量出的「语料上不发生」是假的;换 DPS 视角当场翻出三处真错。

## 取样:跨对局

多窗口抽样必须跨对局,同场样本彼此相关。
